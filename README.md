This repository documents my continuous learning journey, experiments, and practical implementations in the field of Data Science and Machine Learning. It serves as a centralized portfolio encompassing my academic coursework, professional bootcamp submissions, and independent explorations.

## 📂 Repository Structure

To keep things organized and easy to navigate, this repository is divided into three main directories:

### 1. Dicoding Submissions (`/Dicoding Submission`)
This section contains my assignments, model implementations, and final submissions for the **Data Scientist Learning Path** at **Dicoding Coding Camp 3.0**. 
- **[Bank Transaction Segmentation using K-Means](https://github.com/AdhyDa/Learn-Data-Science/tree/main/Dicoding%20Submission/Clustering)**: *An unsupervised machine learning project applying K-Means clustering and Principal Component Analysis (PCA) on banking transaction data. The pipeline includes feature scaling, outlier handling, and cluster evaluation using the Elbow Method and Silhouette Score to uncover distinct customer financial behaviors.* 
- **[Customer Segment Prediction via Random Forest](https://github.com/AdhyDa/Learn-Data-Science/tree/main/Dicoding%20Submission/Classification)**: *A supervised classification model built to predict customer behavior segments derived from K-Means clustering. This project implements Decision Tree and Random Forest algorithms, utilizing One-Hot Encoding for categorical features and GridSearchCV for hyperparameter tuning to optimize prediction accuracy.*

### 2. Personal Projects (`/Personal Experiment`)
My playground for independent research, algorithm testing, and exploratory data analysis (EDA) outside of formal coursework.

### 3. University Assignments (`/University Assignments`)
Contains coursework, practical lab assignments, and academic projects from the Data Science courses I am taking at **Universitas Negeri Malang**.
